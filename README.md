# freshpath-studio/.github

Org-wide default community files for Freshpath Studio repos.

- `.github/ISSUE_TEMPLATE/claude-job.md`: the "Claude job" issue template. Mac-only, TestFlight and device steps go at the top. The canonical rules are in `freshpath-studio/studio` (`claude-wake-standard.md`).

A repo that has its own `.github/ISSUE_TEMPLATE` folder does not inherit these defaults.
